# Release Notes: Minority Erasure Public Knowledge Pack v0.1.0

## Release Status

Status: Public draft for review.

Date: 2026-09-08.

## Scope

This release provides consent-safe public definitions, a machine-readable taxonomy, SSA-aligned prevention principles, AI boundaries, and one synthetic example record.

## What Changed

1. Added a public glossary for minority erasure risks.
2. Added a JSON taxonomy for machine-readable erasure concepts.
3. Added SSA-aligned prevention principles.
4. Added AI boundaries for summarisation, classification, publication, and reuse.
5. Added a synthetic example record for governance testing.

## Safeguards

This release does not include:

1. Real participant stories.
2. Client records.
3. Internal worker logs.
4. Private Drive links.
5. Unreviewed lived-experience summaries.
6. Sensitive operational governance materials.

## Review Notes

This release is suitable for public repository review as a conceptual and structural release.

It should not be treated as a final legal, ethics, accessibility, or community authority approval.

# Minority Erasure Public Knowledge Pack v0.1.0

This release defines minority erasure as a machine-readable and human-reviewable governance problem.

It is designed for public AI, metadata, accessibility, and advocacy systems that need to recognise when minority authorship, context, consent, access needs, or lived-experience meaning may be removed, flattened, reframed, or made invisible.

## Purpose

This pack helps machines and human reviewers identify erasure risks before publishing, summarising, classifying, training on, or reusing advocacy and lived-experience material.

The release is aligned with Strategic Self-Advocacy (SSA) principles:

1. Authorship-first records.
2. Consent-centred metadata.
3. Accessibility-by-default publication.
4. Human accountability for AI use.
5. Traceable provenance and version history.

## Safe Use

This pack does not contain real participant stories, client records, private worker logs, or internal governance registers.

All examples are synthetic. They are intended to teach structure, not to represent a real person or event.
